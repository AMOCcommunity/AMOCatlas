amocvocab — variable vocabulary

Version 0.1, checked against CF standard-name table v94 (2026-06-09). This table is generated from amocatlas/vocabulary/amocvocab.yml.

Each quantity carries a CF standard_name only when an exact CF name exists whose canonical units are convertible to the reported units; otherwise the standard name is null and the nearest CF concept, if any, is noted. See the AMOCatlas data format conformance statement for how these are written into files.
